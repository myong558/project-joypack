# 타임 투 플립 (Time to Flip)

- 게임 ID: `timetoflip`
- 공개: 2026-10-26 12:00(한국 시각) 정식 공개 예약 → v1.0.0 (`pnpm release timetoflip --at "2026-10-26 12:00"`, 처음 잡았던 10-24 23:35 에서 미룸)
- 한 줄 소개: 시간이 다 가기 전에 짝을 찾아라! / Find the pairs before time runs out!
- 한 판: 약 1~3분. 판(스테이지)을 깨면 남은 시간을 들고 다음 판으로 가고, 시간이 0이 되면 끝
- 조작: 카드 누르기(누르는 순간 뒤집힘). 키보드는 화살표로 고르고 Enter·스페이스로 뒤집기, Esc·P 일시정지, 결과 화면 Enter 다시 하기
- 점수·결과: 점수(높을수록 좋음). 결과에 도달한 판·맞힌 짝·최고 콤보·정확도, 새로 모은 카드
- 모드: 클래식(끝없이 이어지는 판) / 오늘의 챌린지(날짜 시드로 모두 같은 카드, 위치는 시도마다 새로 섞음 → 다시 해서 위치를 외울 수 없음)
- 랭킹: `games/timetoflip/rankings/classic`, `daily-YYYY-MM-DD`(순위표 1개 = 문서 1개, `{ name, score, stage, date }`). 점수 높은 순, 동점은 먼저 올린 기록
- 손맛: 아래 "손맛" 표
- 정체성: 째깍째깍 경쾌한 시간 퍼즐 · 글꼴 Do Hyeon(본문·숫자) + Dongle Bold(제목·팝업, Do Hyeon 에 없는 기호도) + Jua(공용 위 메뉴 언어 단추만) · 청록 `#0b7785`(스킨마다 바뀜) · 시간 막대 끝 미니멀 스톱워치(얼굴 없이 바늘 하나가 남은 시간을 가리킴) + 조이팩 로고 얼굴 카드 뒷면 · 로고: 진한 글자 카드 제목(두 단어를 잇는 가운데 "투 / to"만 작은 금색 카드, 누르면 한 바퀴 뒤집힘) 위에 카드 세 장 시연(도형 카드로, 명화는 미리 보이지 않게 · 짝은 보라 육각형, 틀리는 카드는 노랑 초승달 · 1번·2번 열기 → 틀려서 둘 다 덮기 → 1번·3번 열어 짝 → 시간 막대 차오름, 8초 반복, 결과 화면 위에도 같은 크기로, 키 낮은 휴대폰은 작게) · 아이콘: 진한 남보라 바탕(허브 청록 그림판과 구분)에 게임 로고 그대로(보라 육각형 짝 · 가운데 조이팩 얼굴 뒷면 · 시간 막대) · 배경: 캔버스 한 장에 스킨 하늘(위쪽 빛 + 아래로 강조색)·오로라 덩어리 셋·빛 띠·비네트·먼 빛망울·반짝이·별(낮은 해상도 30fps, 창이 열리면 멈춤 · 휴대폰 깜박임 방지), 그 위에 실제 카드 그림이 좌우로 흔들리며 떠올라 뒤집혔다 덮임(가까운 층은 흐릿하게, 게임 중 흐리게) · 시간대 스킨(아침·한낮·노을·밤) · 마림바 같은 사인파, 콤보마다 음이 오름 · 3D 뒤집기·콤보 음계·시간 팝업

- v0.16.0 모의 플레이(실력별 300판): 서툼 평균 3.6판·1분 38초, 보통 6.2판·2분 38초, 잘함 12.1판·4분 27초, 고수 16.7판(최대 18판)·약 5분. 전에는 고수가 평균 133판·44분으로 끝나지 않았음. v1.1.4 확인(tests/balance.test.ts, 실력별 60판 · 돋보기 동안 시간 멈춤 반영): 서툼 3.5판·1분 37초, 보통 5.8판·2분 29초, 잘함 9.4판·3분 48초.
- 시작 40초, 최대 60초까지 쌓임. 판 클리어 +3초, 한 번도 안 틀리면(퍼펙트) +2초 더. 콤보 3 이상이면 짝마다 +0.5초.
- **기억 실수 −1초**(2판부터): 처음 뒤집은 카드의 짝을 **이미 본 적이 있는데** 다른 카드를 고르면 깎음. 처음 보는 카드끼리 틀린 것(탐색)은 깎지 않음 → "아는데 놓쳤다"만 벌을 받아 억울하지 않고, 기억할수록 오래 감.
- 특수 카드: ⏱ 시계(맞히면 +5초) · 🔍 엿보기(맞히면 남은 카드를 1.3초 보여 줌. 보여 주는 동안은 판 시작 미리 보기처럼 시간이 멈추고 누름을 받지 않으며, 시간 막대는 그 자리에 멈추고 스톱워치만 눈으로 바뀜 · v1.1.4). 이 기기에서 처음 깔리는 판의 미리 보기 동안 위 가운데에 두 줄 안내("시계 카드 / 맞히면 +5초", 한 번만, `itemHints`). 도감 맨 아래 "특수 카드" 칸(시계·돋보기·황금)은 처음 맞히면 열리고 효과 설명이 보임(`items`, 48장 모으는 수에는 넣지 않음, v1.1.0). 카드 모습(v1.1.3): 보통 카드 바탕 + 은 액자, 청록 입체 아이콘에 금 포인트(종·다리·바늘 중심·손잡이 고리) — 황금 카드(금 액자 + ★)와 금·은으로 이어지는 한 세트, 보통 카드(액자 없음)와 한눈에 구분. 도감 특수 카드 칸도 같은 모습.
- 황금 카드: 2판부터 판마다 18% 확률로 보통 짝 하나가 황금(점수 2배). 도감에 ★ 기록은 남기지 않음(운이라 실력과 무관해 v0.11.0 에서 뺌). 앞면은 두꺼운 금 액자 + 오른쪽 위 ★ + 바깥 금빛(외우는 시간·뒤집을 때 같게 보여 헷갈리지 않게, 움직이는 반짝임은 앞면이 잠깐만 보여 의미가 없어 넣지 않음). 맞히면 두 장이 금빛으로 번쩍이며 크게 튀고 ★가 톡 커짐. 처음 깔리는 판에 "황금 카드 / 맞히면 점수 2배" 안내(v1.1.1).
- 점수: 짝 100 × 콤보 배수(1, 1.5, 2 … 최대 5) + 기억 보너스 50(두 장 다 본 카드) / 럭키 20(두 장 다 처음 본 카드), 판 보너스 = 판 × 200(+퍼펙트 500).
- 미리 보기: 카드가 0.6초 동안 깔린 뒤(카드 수와 관계없이) 표의 시간만큼 모두 보여 줌. 카드가 늘수록 조금 길어지지만 장당 시간은 줄어(1판 0.17초 → 6판 0.09초) 점점 어려워지고, 높은 판도 2.6초 아래로 내려가지 않음. 시간은 멈추고, 아무 카드나 누르면 건너뛰고 바로 뒤집힘(깔리는 0.6초 동안의 누름은 무시). 미리 보기 동안 시간 막대는 "외우는 시간"으로 바뀜: 레몬색으로 줄어들고 스톱워치 대신 눈, 숫자 칸은 레몬색 카드 뒷면으로 덮였다가 미리 보기가 끝나면 카드처럼 뒤집혀 게임 시간이 나타남(넘김 소리). 위 가운데에 짧은 안내(1판 "위치를 기억하세요", 새 묶음 이름, 5·8판 "닮은 카드 주의!"). 틀린 두 장은 0.65초 보이고, 그 전에 다음 카드를 누르면 바로 덮임(손이 빠른 사람이 막히지 않게).
- 일시정지 중에는 카드 그림을 가림(멈춰 놓고 외우지 못하게).

## ⛔ 앱 출시 때 필수 (기준서 10.6)

- **게임 판 화면 캡처 막기(치팅 방지)**: 미리 보기 때 카드를 캡처해 두고 보며 맞히는 것을 막는다. 웹은 막을 수 없어 마켓 앱으로 낼 때 꼭 넣는다.
  - 안드로이드: 미리 보기·플레이 동안만 `FLAG_SECURE`(시작·결과 화면은 끔). TWA 로는 안 되므로 웹뷰 앱(Capacitor 등)으로 감싼다.
  - iOS: 막을 수 없음 → 화면 녹화 중이면 판을 가리고, 스크린샷을 찍은 판은 랭킹에 올리지 않는다.

## 게임 화면 위쪽

- 반투명 유리판 하나에 일시정지 · 판 · 콤보 · 점수(이름표 + 고정폭 숫자) · **빠른 재시작**(일시정지 없이 같은 모드·같은 시작 판으로 바로 새 판)
- 시간 막대: 시작 시간 40초가 꽉 찬 상태. 40초보다 많이 모으면 가득 찬 채 금빛으로 빛나고(숫자로 남은 시간), 막대 위로 빛이 천천히 지나감. 막대는 양쪽을 마스코트 반 폭씩 들여 마스코트 가운데가 늘 막대 끝을 따라가고, 0초에는 왼쪽 끝까지 가되 몸이 레일 밖으로 나가지 않음

| 동양화 · 수묵 | 6 | 수묵화 8점(탄은 이정·김농·마수진·석도·팔대산인·예찬·심주), 흑백. 일본 작품은 팝아트로 본 명화의 호쿠사이 「파도」 한 점만 | 색이 없어 가장 어려움 |

- 도감: 위 가운데 큰 카드(처음엔 뒷면)와 설명 칸, 아래 묶음별 작은 카드. 작은 카드를 누르면 큰 카드가 뒤집혀 그 그림으로 바뀌고 제목·작가·짧은 설명이 나온다. 명화는 실제 작가·연도·이야기, 도형·팝아트는 작가 줄이 "그림 조이팩"(직접 그린 그림임을 밝힘)이고 설명은 지어낸 우스개. 큰 카드가 주인공(150×192, 키 낮은 휴대폰은 112×144)이고 아래 작은 카드 목록만 스크롤된다. 설명은 카드마다 두 줄 길이로 맞춰 써서 설명 칸 높이가 늘 같다. 큰 카드는 고풍 앤티크 금 액자(`src/ui/frame.ts`, 루이 15세풍 물결 테·조각·구슬 띠, SVG 조명 필터로 입체) 안에 있고, 액자는 고르기 전부터 그대로 두고 안의 카드만 뒤집힌다.
- 출시 전 확인용으로 개발자 도구가 켜진 동안(`Joypack.devTools()`)만 도감 48장이 모두 열려 보인다(`src/ui/screens.ts` `DEX_ALL_OPEN`, 저장된 기록은 그대로). 정식 공개하면 자동으로 저장된 기록대로 보인다.
- 카드 뒷면: 조이팩 로고 얼굴을 새긴 볼록한 메달 + 사선 줄무늬·이중 테두리·모서리 점, 카드마다 시차를 두고 빛줄기가 지나감(동작 줄이기면 멈춤).

## 중독성 장치

| 고리 | 장치 |
| --- | --- |
| 매 순간 | 3D 뒤집기, 맞힐 때마다 콤보 음이 한 칸씩 오름, `+점수`·`+초` 팝업, 별 파티클 |
| 한 판 | 시간 저축(남은 시간이 다음 판으로), 퍼펙트 보너스, 판마다 새 카드 묶음 배너 |
| 한 게임 | 결과에 "다음 판까지 N쌍 남았었어요"·"최고 기록까지 N점", 다시 하기 한 번에 바로 시작 |
| 하루 | 오늘의 챌린지(모두 같은 카드, 위치는 시도마다 섞음)와 하루 순위표 |
| 오래 | 카드 도감 48장(뒤쪽 묶음은 멀리 가야 나옴) |

연속 출석 압박, 놓치면 사라지는 보상, 돈으로 사는 뽑기는 두지 않음(상업 기준 10.5).
