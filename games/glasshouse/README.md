# 온실 정원 (Glasshouse Garden)

- 게임 ID: `glasshouse`
- 공개: 미리보기(개발자 모드, v0.1.0) — 휴대폰 확인 뒤 `pnpm release glasshouse`
- 한 줄 소개: 햇살 길을 읽고 화분을 밀어 꽃을 피우세요 / Read the sunbeams, push the pots, bring the flowers out
- 한 판: 정원(판) 하나 약 30초~2분. 모든 화분이 제 습성에 맞는 자리에 놓이면 꽃이 피며 끝난다(실패로 끝나는 일은 없고, 막히면 되돌리기·처음부터). 정원 24개(계절마다 6개)
- 조작: 판 위에서 밀기(한 칸씩, 손을 떼지 않고 계속 밀면 일정 거리마다 한 칸 더), 옆 칸 누르기(한 걸음), 먼 칸 누르기(화분을 밀지 않는 가장 짧은 길로 걸어감). 키보드 화살표·WASD, Z·Backspace 되돌리기, R 처음부터, Esc·P 일시정지, 결과 화면 Enter 다음 정원
- 점수·결과: 판 점수 = 기준 이동 수(풀이기가 찾은 가장 적은 이동) 이하면 1000, 많으면 1000 × 기준 ÷ 이동(10점 단위, 최소 100). 꽃잎 3장(기준 이하) · 2장(기준의 1.3배까지) · 1장. **정원 점수** = 24개 판 가장 좋은 판 점수의 합(최대 24,000)
- 모드: 정원 24개를 차례로(앞 정원을 가꾸면 다음이 열림), 깬 정원은 언제든 다시(더 적은 이동으로 기록 갱신). **오늘의 정원**: 날마다 새 판 하나, 모두 같은 판(봄 정원 여섯을 모두 피우면 열림). 판의 계절 = 그날 달력 계절(오늘이 가을이면 반사판 판), 판 위에 그 계절 요소 안내 한 줄. 걸린 시간을 재고(일시정지·화면 떠남은 빼고) 몇 번이든 다시 할 수 있음. 결과 화면 큰 단추는 "한 번 더 하기"(다음 판이 없어 기준서 1.3 기본대로)
- 랭킹 두 탭(순위표 1개 = 문서 1개): **정원 점수** `games/glasshouse/rankings/garden`(`{ name, score, flowers, date }`, 점수 높은 순, 동점은 먼저 올린 기록) · **오늘의 정원** `daily-YYYY-MM-DD`(`{ name, moves, time, date }`, 이동 수 적은 순 → 시간 짧은 순, 매일 자정 새 문서). 둘 다 **같은 이름은 가장 좋은 한 줄만** 남김(정원 점수는 누적, 오늘의 정원은 여러 번 해서, 서버 규칙도 검사). 허브 전체 랭킹에서 오늘의 정원은 "18회 · 42.0초"처럼 횟수·시간으로 보임

## 규칙

| 칸 | 모습 | 사람 | 화분 | 햇살 |
| --- | --- | --- | --- | --- |
| 돌바닥 `.` | 판석 두 가지 색 | 지나감 | 밀림 | 지나감 |
| 벽 `#` | 벽돌 화단 턱(위에 이끼) | 막힘 | 막힘 | 막힘 |
| 창 `v ^ < >` | 벽에 끼운 십자 창살 유리, 빛남 | 막힘 | 막힘 | 화살표 쪽으로 햇살 줄기가 들어옴 |
| 물길 `~` (여름부터) | 잔물결이 흐르는 푸른 물 | 막힘 | 막힘 | 지나감 |
| 반사판 `/ \` (가을부터) | 놋쇠 틀 거울판 | 막힘 | 막힘 | 90° 꺾임 |
| 언 물길 `=` (겨울) | 금 간 옅은 얼음 | 걸어 다님 | 막힐 때까지 미끄러짐 | 지나감 |

- **햇살 줄기**는 창에서 곧게 나아가다 벽이나 **화분에 닿으면 멈춘다**. 그 화분은 햇볕을 받고, 그 뒤는 그늘. 그래서 줄기 하나는 화분 하나만 비추고, 햇살 꽃 화분으로 그늘 꽃을 가려 줄 수 있다(정원사는 빛을 가리지 않음).
- 화분의 습성(화분에 찍힌 도장): **햇살 꽃**(해) = 햇살이 닿아야 핌 · **그늘 꽃**(나무 그늘) = 햇살이 닿지 않아야 핌 · **물가 꽃**(물방울) = 물길 바로 옆(상하좌우)에서 핌(언 물길은 아님).
- 모든 화분이 맞으면 판을 깸: 화분마다 차례로 꽃잎이 천천히 벌어지고 결과 화면.
- 맞는 자리에 놓인 화분은 꽃대가 서고 바닥이 빛나며 도장이 밝아짐. 다시는 피울 수 없게 구석에 몰린 화분(햇살 줄기가 아예 지나가지 않는 구석의 햇살 꽃, 물길에서 먼 구석의 물가 꽃)이 생기면 도장이 빨갛게 되고 위에 "되돌리기" 안내.
- 처음 나오는 규칙은 그 판 위에 한 줄로 알림(봄 1 "화분을 밀어 햇살 줄기 속에", 봄 2 "줄기 하나는 화분 하나만", 봄 4 그늘 꽃, 여름 1 물가 꽃, 가을 1 반사판, 겨울 1 언 물길). 아래에는 그 판에 나온 습성만 설명 칩.

## 정원(판) 만들기

- 판은 `tools/levelgen.ts`(배포 안 됨, `pnpm --filter glasshouse levels <계절> <화분 S,SH…> <밀기 최소-최대> <개수> [시드]`)가 무작위 온실 방을 만들어 풀이기(`src/game/solver.ts`, 너비 우선 탐색)로 풀고, **처음부터 맞는 화분이 없고 · 그 계절 요소를 써야만 깨지고(가을은 반사판에 꺾인 빛을 받는 화분, 겨울은 미끄러짐) · 막히는 상태가 많고 깨는 상태가 적은** 판만 점수를 매겨 고른 것. 그 가운데 계절마다 쉬운 판부터 6개를 손으로 골랐다.
- `tests/levels.test.ts` 가 판마다 다시 풀어 기준 이동 수(par)·계절 요소·꽃 습성을 확인한다.
- 방 만들기·거르기·어려움 점수는 `src/game/roomgen.ts` 하나를 판 만들기 도구와 오늘의 정원 판 만들기가 같이 쓴다.

### 오늘의 정원 판

- `tools/dailygen.ts`(배포 안 됨)가 날짜마다 날짜 시드로 그 계절 방을 만들어 같은 기준(처음부터 맞는 화분 없음 · 계절 요소를 써야 깸 · 기준 이동 14~40 · 밀기 4~14, 상태 6만 개 이하)으로 거르고, 쓸 만한 후보 6개 가운데 가장 어려운 판을 골라 `src/game/daily-data.ts` 에 하루 한 줄(`계절 글자 + 기준 이동|줄|줄…`)로 적는다. 2026-10-25 ~ 2027-12-31(433일, 약 31KB). 시드가 달라도 난수 수열이 겹쳐 앞 날과 같은 판이 나오면 merge 가 뒤 날을 다른 시드로 다시 만든다.
- 게임 안에서 만들지 않는 까닭: 판 하나를 고르는 데 PC에서도 1~9초(가을 반사판 판이 가장 느림)라 휴대폰에서는 너무 느리고, 미리 만들면 테스트로 다시 확인할 수 있다. 목록이 끝난 뒤 날짜는 처음부터 다시 돈다.
- **목록 늘리기(2027년 말 전에)**: `pnpm --filter glasshouse daily <시작 날짜> <날 수> <결과.json>` 을 날짜 구간마다 동시에 돌리고(8개로 나누면 약 20분), `pnpm --filter glasshouse daily merge <결과.json …>` 으로 합친다. 이미 지난 날짜의 판은 바꾸지 않는다(그날 순위표와 어긋남). `tests/daily.test.ts` 가 날짜·계절·기준 이동 범위를 모두, 기준 이동 수·계절 요소는 열흘에 하루씩 다시 풀어 확인한다.
- 꽃: 화분 습성과 판 계절이 같은 꽃 가운데 이미 도감에 연 꽃을 먼저, 날마다 돌아가며(아직 못 본 꽃을 미리 보이지 않게). 오늘의 정원은 도감을 열지 않는다.

## 재미 설계 (기준서 11.2)

| 기둥 | 무엇으로 |
| --- | --- |
| 손맛 | 테라코타가 돌바닥을 긁는 스르륵 + 진동 35, 판이 아래로 톡, 맞는 자리에 놓이면 종소리·햇빛 고리·꽃대가 섬, 언 물길 미끄러짐(휙 + 오름 진동), 판을 깨면 꽃잎이 실제로 벌어지는 개화 |
| 판단 | 어느 화분을 어느 줄기에 넣을지(줄기 하나에 하나), 햇살 꽃으로 그늘 꽃을 가릴지, 미는 순서(구석에 몰면 끝), 반사판으로 꺾인 길·미끄러져 멈출 곳 읽기 |
| 욕심 | 꽃잎 3장(기준 이동), 정원 점수 랭킹, 오늘의 정원(날마다 새 판, 이동·시간 순위), 도감 24쪽(못 연 쪽은 연필 윤곽만), 계절마다 새 요소 |

- 한 판 길이와 끝: 판은 깨면 끝(실패 없음). 판마다 기준 이동 12~50.
- 난이도 곡선: 봄 1 은 화분 하나·줄기 하나(밀기 4번). 계절마다 새 요소 하나를 그 계절 첫 판에서 알리고, 뒤로 갈수록 화분 수와 막히는 상태가 늘어남. 시간 제한이 없어 반응 속도가 아니라 내용으로 어려워짐.
- 운 요소 없음: 판은 고정, 점수는 이동 수만.
- 치팅: 판이 고정이라 풀이를 외우거나 남의 풀이를 볼 수 있음(퍼즐 장르의 한계). 점수는 서버 규칙이 상한(깬 판 × 1000)·10점 단위·하한을 검사. 정원 점수 1위가 같은 점수로 모이면 먼저 올린 사람이 앞섬. 오늘의 정원은 판을 받는 그날 처음 보므로 외우기 어렵고, 기준 이동에 모이면 시간으로 갈림(서버는 이동 1~999·시간 1초~하루·날짜만 검사).
- 재도전: 판 중 **되돌리기**(이동 수도 되돌림 → 끝까지 해 보고 줄일 수 있음)·**처음부터**(빠른 재시작), 결과 화면 "다음 정원"·"다시 하기", 결과의 다음 목표("N번만 줄이면 꽃잎 3장").
- 도움: 되돌리기는 무제한이지만 점수는 깬 순간의 이동 수라 손해가 없음. 막힘 안내는 다시는 못 깨는 확실한 경우에만.

## 모의 플레이 (기준서 11.2-3, `tests/balance.test.ts`)

봇은 걸음마다 실력 확률로 깨는 데 가까워지는 수를 두고 아니면 아무 데로나 움직이며, 막힌 상태에 빠지면 몇 걸음 헤맨 뒤 되돌린다. 시간 = 손 걸음 × 0.4초 + 화분을 민 번마다 생각 시간(서툼 4초 · 보통 3 · 잘함 2 · 고수 1.2) + 막힐 때마다 6초. 판마다 12번(v0.1.0).

## 요소와 이유 (기준서 11.4)

| 요소 | 무엇을 위한 것 |
| --- | --- |
| 햇살 줄기(빛 띠) | 판단: 어느 칸이 햇볕인지 한눈에. 화분에 닿으면 끝이 멈춰 "가린다"가 보임 |
| 화분 도장(해·나무 그늘·물방울) | 이해: 화분마다 습성 |
| 꽃대가 섬·바닥 빛·도장 빛 | 손맛·이해: 맞는 자리에 놓였음 |
| 빨간 도장 + "되돌리기" | 이해: 다시는 못 깨는 상태를 알려 헛수고를 줄임 |
| 이동 / 기준 | 욕심: 꽃잎 3장 목표 |
| 아래 습성 칩 | 이해: 그 판에 나온 규칙만 짧게 |
| 꽃잎 1~3장 | 욕심: 같은 판을 더 적게 |
| 도감 책(넘기는 쪽) | 욕심(수집)·보상: 판을 깰 때마다 실제 꽃 한 쪽 |
| 계절빛 스킨 | 정체성: 정원의 계절이 배경 빛·꽃잎과 이어짐 |

## 식물 도감

- 오래된 식물 도감 한 쪽처럼: 미색 종이(옅은 섬유·얼룩), 겹줄 테두리 안 삽화, 꽃 이름(명조), 학명(기울임), 꽃말·피는 때·원산지·습성(아이콘), 짧은 설명 두 문장, 쪽 번호. 휴대폰은 위 삽화·아래 글, 넓은 화면·가로는 왼쪽 삽화·오른쪽 글.
- 차례(0쪽) + 꽃 24쪽. 앞·뒤 단추·가로 밀기·화살표 키로 넘기면 종이가 책등을 축으로 넘어감(동작 줄이기면 바로 바뀜). 못 연 쪽은 연필 윤곽처럼 흐린 그림과 "○ ○ 정원을 가꾸면 열려요". 차례에서 눌러 바로 그 쪽으로.
- 타임 투 플립 도감(카드 격자 + 큰 카드)과 겹치지 않게 책 모양·쪽 넘김으로 함.
- 꽃말 확인: 구절초(어머니의 사랑)·포인세티아(축복)·복수초(영원한 행복)는 기사로 다시 확인함. 나머지는 널리 쓰이는 꽃말을 적었고, **출시 전에 농촌진흥청 국립원예특작과학원 "오늘의 꽃"으로 한 번 더 확인**(특히 꽃창포 "우아한 마음", 과꽃 "추억", 수련 "청순한 마음", 꽃무릇 "이룰 수 없는 사랑", 국화 "고결", 크리스마스로즈 "나의 불안을 달래 주세요", 시클라멘 "수줍음", 달리아 "감사"). 영어 화면은 같은 꽃말을 옮긴 것.
- 꽃 그림은 `src/ui/flowers.ts` 가 꽃잎·잎 모양 몇 가지를 조합해 그린다(꽃 하나 그리는 코드 약 0.5~1.5KB). 꽃잎마다 핀 각도·오므린 각도를 두어 같은 그림으로 봉오리부터 개화까지 움직인다.
