# 온실정원 (Glasshouse Garden)

- 게임 ID: `glasshouse`
- 공개: 미리보기(개발자 모드, v0.3.0) — 임시 판 7개를 고품질 판으로 바꾸고(아래 "정원(판) 만들기") 휴대폰 확인 뒤 `pnpm release glasshouse`
- 한 줄 소개: 화분을 밀어 창가 햇살 자리에 꽃을 피우세요 / Push the pots into the sunny spots and bring the flowers out
- 한 판: 정원(판) 하나 약 30초~2분. 모든 화분이 창 앞 햇살 자리에 놓이면 꽃이 피며 끝난다(상자 밀기 규칙)(실패로 끝나는 일은 없고, 막히면 되돌리기·처음부터). 정원 24개(꽃 한 종씩, 계절 구분 없음)
- 조작: 판 위에서 밀기(한 칸씩, 손을 떼지 않고 계속 밀면 일정 거리마다 한 칸 더), 옆 칸 누르기(한 걸음), 먼 칸 누르기(화분을 밀지 않는 가장 짧은 길로 걸어감). 키보드 화살표·WASD, Z·Backspace 되돌리기, R 처음부터, Esc·P 일시정지, 결과 화면 Enter 다음 정원
- 점수·결과: 판 점수 = 기준 이동 수(풀이기가 찾은 가장 적은 이동) 이하면 1000, 많으면 1000 × 기준 ÷ 이동(10점 단위, 최소 100). 꽃잎 3장(기준 이하) · 2장(기준의 1.3배까지) · 1장. **정원 점수** = 24개 판 가장 좋은 판 점수의 합(최대 24,000)
- 모드: 정원 24개를 차례로(앞 정원을 가꾸면 다음이 열림), 깬 정원은 언제든 다시(더 적은 이동으로 기록 갱신). **오늘의 정원**: 날마다 새 판 하나, 모두 같은 판(처음부터 조건 없이 열림, 시작 화면 "이어 가꾸기" 바로 아래, v0.5.6 사용자 결정: 날마다 다시 오게 하는 장치라 첫날부터 순위 경쟁에 끼게. 정원 1을 아직 안 깬 사람에게는 판 위에 첫 규칙 안내, 꽃은 튤립). 방 크기·화분 수는 그날 달력 계절 단계를 따름(판 생성용, 꽃·스킨과는 상관없음). 걸린 시간을 재고(일시정지·화면 떠남은 빼고) 몇 번이든 다시 할 수 있음. 결과 화면 큰 단추는 "한 번 더 하기"(다음 판이 없어 기준서 1.3 기본대로)
- 랭킹 두 탭(순위표 1개 = 문서 1개): **정원 점수** `games/glasshouse/rankings/garden`(`{ name, score, flowers, date }`, 점수 높은 순, 동점은 먼저 올린 기록) · **오늘의 정원** `daily-YYYY-MM-DD`(`{ name, moves, time, date }`, 이동 수 적은 순 → 시간 짧은 순, 매일 자정 새 문서). 둘 다 **같은 이름은 가장 좋은 한 줄만** 남김(정원 점수는 누적, 오늘의 정원은 여러 번 해서, 서버 규칙도 검사). 허브 전체 랭킹에서 오늘의 정원은 "18회 · 42.0초"처럼 횟수·시간으로 보임

## 규칙

| 칸 | 모습 | 사람 | 화분 |
| --- | --- | --- | --- |
| 돌바닥 `.` | 판석 두 가지 색 | 지나감 | 밀림 |
| 벽 `#` | 벽돌 화단 턱(위에 이끼) | 막힘 | 막힘 |
| 창 `v ^ < >` | 바깥 벽에 끼운 십자 창살 유리, 빛남 | 막힘 | 막힘 |
| 햇살 자리 | 창 바로 앞(화살표 쪽) 한 칸, 창에서 들어온 빛 띠 + 바닥에 고인 동그란 빛 | 지나감 | 놓으면 꽃대가 섬 |

- 고전 상자 밀기 규칙 그대로: 정원사는 상하좌우로 걷고, 앞의 화분을 **한 칸 민다**. 화분 뒤가 벽이나 다른 화분이면 못 밀고, **당기기는 없다**.
- 창 수 = 화분 수. **모든 햇살 자리에 화분이 놓이면** 판을 깸: 화분마다 차례로 꽃잎이 천천히 벌어지고 결과 화면. 어느 화분이 어느 자리에 가도 된다.
- 햇살 자리에 놓인 화분은 꽃대가 서고 바닥이 빛나며 맑은 종소리. 햇살 자리가 아닌 구석(위아래 한 면 + 좌우 한 면이 벽)에 몰려 다시는 못 빼는 화분이 생기면 화분 테두리가 빨갛게 되고 위에 "되돌리기" 안내.
- 판 위 한 줄 안내: 정원 1 "화분을 밀어 창 앞 햇살 자리에", 정원 2 "밀기만 돼요 · 구석에 넣으면 못 빼요", 정원 3(처음 화분 2개) "자리마다 하나씩 · 미는 순서". 아래에는 "햇살 자리" 설명 칩 하나.
- 화분 꽃: 판마다 그 판의 꽃 한 종만(화분이 여럿이어도 모두 같은 꽃, 깨면 도감에 열림, v0.5.3 사용자 요청). 오늘의 정원은 이미 연 꽃 가운데 그날의 한 종.

## 정원(판) 만들기

- 판은 `tools/picklevels.ts`(배포 안 됨, `pnpm --filter glasshouse picklevels [--quick] [판 번호 …]`)가 판마다 정한 계절 방 크기·화분 수·기준 이동 범위(난이도 곡선)로 무작위 온실 방(`src/game/roomgen.ts`)을 만들어 풀이기(`src/game/solver.ts`, 너비 우선 탐색)로 풀고, **처음부터 햇살 자리에 화분이 없고 · 막히는 상태가 많고 깨는 상태가 적은** 판을 점수로 골라 쉬운 판부터 놓은 것(방 크기 단계 이름은 roomgen 의 spring~winter, 화면에는 안 보임). 하나씩 시험할 때는 `tools/levelgen.ts`.
- **임시 판(v0.3.0)**: 화분 3개 고품질 판(상태 30만 개까지 탐색, 후보 12개)은 하나 고르는 데 몇 분~수십 분이 걸려, 정원 15·17·18·21~24 의 7판은 `--quick`(상태 6만 개까지, 후보 4개)로 만든 임시 판이다(`levels.ts` 에 "임시 판" 주석). **정식 공개 전에 `pnpm --filter glasshouse picklevels 14 16 17 20 21 22 23`(판 번호 0부터, 판마다 따로 동시에 돌려도 됨)처럼 고품질로 다시 골라 바꾼다**(기준서 0장 "판 생성이 오래 걸리는 게임"·7.4 0단계).
- `tests/levels.test.ts` 가 판마다 다시 풀어 기준 이동 수(par)·첫 화분 꽃·화분 수 곡선을 확인한다.

### 오늘의 정원 판

- `tools/dailygen.ts`(배포 안 됨)가 날짜마다 날짜 시드로 그 계절 방을 만들어 같은 기준(처음부터 햇살 자리에 화분 없음 · 기준 이동 14~40 · 밀기 4~14, 상태 6만 개 이하)으로 거르고, 쓸 만한 후보 6개 가운데 가장 어려운 판을 골라 `src/game/daily-data.ts` 에 하루 한 줄(`계절 글자 + 기준 이동|줄|줄…`)로 적는다. 2026-10-25 ~ 2027-12-31(433일). 시드가 달라도 난수 수열이 겹쳐 앞 날과 같은 판이 나오면 merge 가 뒤 날을 다른 시드로 다시 만든다.
- 상자 밀기 규칙으로 바꾼 뒤(v0.3.0)는 433일을 8개로 나눠 몇 분이면 다 만든다. 그래도 게임 안에서 만들지 않는 까닭: 날짜마다 같은 판이 나와야 하고, 미리 만들면 테스트로 다시 확인할 수 있다. 목록이 끝난 뒤 날짜는 처음부터 다시 돈다.
- **목록 늘리기(2027년 말 전에)**: `pnpm --filter glasshouse daily <시작 날짜> <날 수> <결과.json>` 을 날짜 구간마다 동시에 돌리고, `pnpm --filter glasshouse daily merge <결과.json …>` 으로 합친다. 이미 지난 날짜의 판은 바꾸지 않는다(그날 순위표와 어긋남). `tests/daily.test.ts` 가 날짜·계절·기준 이동 범위를 모두, 기준 이동 수는 열흘에 하루씩 다시 풀어 확인한다.
- 꽃: 이미 도감에 연 꽃 가운데 날마다 한 종을 돌아가며 모든 화분에(아직 못 본 꽃을 미리 보이지 않게). 오늘의 정원은 도감을 열지 않는다.

| 욕심 | 꽃잎 3장(기준 이동), 정원 점수 랭킹, 오늘의 정원(날마다 새 판, 이동·시간 순위), 도감 24장(못 연 쪽은 연필 윤곽만), 갈수록 넓어지는 방·늘어나는 화분 |

- 한 판 길이와 끝: 판은 깨면 끝(실패 없음). 판마다 기준 이동 9~57.
- 난이도 곡선: 정원 1 은 화분 하나·창 하나(밀기 5번). 정원 3 부터 화분 2개, 정원 14 부터 3개. 여섯 판마다 방이 넓어지고 기준 이동·막히는 상태가 늘어남. 시간 제한이 없어 반응 속도가 아니라 내용으로 어려워짐.
- 운 요소 없음: 판은 고정, 점수는 이동 수만.
- 치팅: 판이 고정이라 풀이를 외우거나 남의 풀이를 볼 수 있음(퍼즐 장르의 한계). 점수는 서버 규칙이 상한(깬 판 × 1000)·10점 단위·하한을 검사. 정원 점수 1위가 같은 점수로 모이면 먼저 올린 사람이 앞섬. 오늘의 정원은 판을 받는 그날 처음 보므로 외우기 어렵고, 기준 이동에 모이면 시간으로 갈림(서버는 이동 1~999·시간 1초~하루·날짜만 검사).
- 재도전: 판 중 **되돌리기**(이동 수도 되돌림 → 끝까지 해 보고 줄일 수 있음)·**처음부터**(빠른 재시작), 결과 화면 "다음 정원"·"다시 하기", 결과의 다음 목표("N번만 줄이면 꽃잎 3장").
- 도움: 되돌리기는 무제한이지만 점수는 깬 순간의 이동 수라 손해가 없음. 막힘 안내는 다시는 못 깨는 확실한 경우에만.

## 요소와 이유 (기준서 11.4)

| 요소 | 무엇을 위한 것 |
| --- | --- |
| 창 + 햇살 자리(빛 띠·고인 빛) | 이해: 목표 칸이 설명 없이 보임(창 바로 앞에만 빛) |
| 꽃대가 섬·바닥 빛 | 손맛·이해: 햇살 자리에 놓였음 |
| 빨간 화분 테두리 + "되돌리기" | 이해: 다시는 못 빼는 화분을 알려 헛수고를 줄임 |
| 이동 / 기준 | 욕심: 꽃잎 3장 목표 |
| 아래 "햇살 자리" 칩 | 이해: 규칙 한 줄 |
| 꽃잎 1~3장 | 욕심: 같은 판을 더 적게 |
| 도감(큰 카드 + 작은 카드 24장) | 욕심(수집)·보상: 판을 깰 때마다 실제 꽃 한 장 |
| 정원 고르기(꽃 카드 24장) | 욕심: 꽃을 보고 다시 가꿀 정원 고르기 |
| 날씨 톤 스킨(맑음·비·노을·눈) | 정체성·지루함 덜기: 자동이면 날마다·정원마다 바깥 날씨가 바뀜(꽃·규칙과는 상관없음, 2026-10-25 사용자 결정: 온실이라 계절과 꽃을 잇지 않음) |

## 식물 도감

- 짜임은 타임 투 플립 도감과 같다(v0.4.0, 사용자 요청): 위 가운데 큰 카드(처음엔 온실 아치 창 표지인 뒷면) + 그 아래 설명, 아래쪽에 정원 순서대로 작은 카드 24장(목록만 스크롤, 계절 구분 없음). 작은 카드를 누르면 큰 카드가 뒤집혀 그 꽃이 펼쳐짐(앞면끼리는 옆으로 세웠다 다시 펼침, 동작 줄이기면 바로 바뀜).
- 도감 판은 꽃 머리가 튤립과 같은 높이·가운데에 오게 판마다 잘라 키움(줄기 밑은 판 아래 끝 그대로, `flowers.ts` dexBox, v0.5.2). 도감 그림은 꽃잎 밑동 그늘·가장자리 밝은 테·가는 결, 잎 한쪽 그늘, 줄기 빛 줄로 입체감을 더함. 작은 카드를 누르면 큰 카드에 봉오리(꽃잎이 길이는 그대로 좁게 오므라져 위로 모이고, 꽃받침이 있는 꽃은 초록 꽃받침이 감쌈)로 펼쳐졌다가 꽃잎이 양쪽으로 차례로 벌어지며 핌, 꽃받침은 아래로 젖혀지고 꽃술은 꽃잎과 함께 펼쳐짐. 줄기 끝이 꽃 머리보다 아래에서 끝나던 꽃은 꽃 머리 밑동까지 줄기를 이음(봉오리가 떠 보이지 않게). 잔꽃이 모인 꽃(히아신스·은방울꽃·물망초·수국·라벤더·꽃무릇)은 봉오리 때 연두빛이었다가 피면서 꽃 색이 차오르고, 잔꽃마다 꽃자루로 줄기·꽃대와 이어짐. 게임 화분·로고도 같은 봉오리(v0.5.9). 큰 카드는 창 높이의 약 3분의 1(휴대폰 약 280px, 키 낮은 폰은 30%, 가로 화면은 작게), 앞면은 오래된 식물 도감 한 쪽처럼 미색 종이 + 겹줄 테두리 속 **사실적인 삽화**(잎·꽃잎 결까지). 설명 칸: 꽃 이름(명조), 학명(기울임) · 꽃말, 피는 때 · 원산지(한 줄), 짧은 설명(최대 3줄). 옛 규칙의 꽃 습성(햇볕·반그늘·물가 "좋아하는 곳")은 v0.5.1 에서 뺌. 칸 높이 고정이라 글 길이가 달라도 목록이 안 움직임.
- 작은 카드는 게임 화분과 같은 약식 그림, 못 연 꽃은 자물쇠. 핀 뒤 아직 안 본 꽃은 오른쪽 위 점(보면 사라짐, 시작 화면 NEW 와 같은 기록). 결과 화면 "도감"은 그 꽃을 펼친 채 연다.
- 꽃말 확인: 구절초(어머니의 사랑)·포인세티아(축복)·복수초(영원한 행복)는 기사로 다시 확인함. 나머지는 널리 쓰이는 꽃말을 적었고, **출시 전에 농촌진흥청 국립원예특작과학원 "오늘의 꽃"으로 한 번 더 확인**(특히 꽃창포 "우아한 마음", 과꽃 "추억", 봉선화 "나를 건드리지 마세요", 꽃무릇 "이룰 수 없는 사랑", 국화 "고결", 크리스마스로즈 "나의 불안을 달래 주세요", 시클라멘 "수줍음", 달리아 "감사"). 영어 화면은 같은 꽃말을 옮긴 것.
- 꽃 그림은 `src/ui/flowers.ts` 가 꽃잎·잎 모양 몇 가지를 조합해 그린다(꽃 하나 그리는 코드 약 0.5~1.5KB). 꽃잎마다 핀 각도·오므린 각도를 두어 같은 그림으로 봉오리부터 개화까지 움직인다.
- 그림은 두 가지(v0.4.0): **도감**(`'dex'`)은 잎·잎의 곁맥·꽃잎 양옆 결까지 그린 100×120 전체, **게임**(`'game'`)은 칸이 작아 잎·결을 빼고 꽃마다 정한 꽃 머리 자리(`FOCUS`)를 가운데로 바짝 잘라 온 정사각형 약식(화분 위·정원 고르기·도감 작은 카드). 꽃 머리가 그림 가운데가 아닌 꽃(수선화·은방울꽃·설강화 등)도 화분 가운데에 곧게 선다. 게임의 봉오리는 조금 크게(점처럼 사라지지 않게).
- 꽃 고르기: 화분에 심어 키울 수 있는 꽃만. 물 위에 잎·꽃을 띄우는 수련은 빼고 여름에 화분에 흔히 키우는 봉선화(Impatiens balsamina)로 바꿈(v0.4.0).
- 화분: 칸 하나 안에 꽃과 함께 들어가도록 낮고 넓은 테라코타(40×26, 칸 폭 80% · 칸 아래쪽), 꽃은 같은 칸 위쪽 74%(줄기 끝은 화분 테두리 뒤). 크기만 줄이면 화분이 납작한 점처럼 보여, 키를 줄이고 입구를 넓혀 작아도 화분으로 읽히게 다시 그림.
