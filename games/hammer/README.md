# 두더지잡기 (Project Hammer)

브라우저에서 바로 즐기는 두더지 잡기(Whack-a-Mole) 게임입니다.
이 문서는 제작 플랜이며, 구현이 진행되면 각 항목을 갱신합니다.

> **한 줄 컨셉**: 30초 동안 성격 다른 두더지들과 벌이는 손맛 대결. 끝나면 "한 판만 더"가 절로 나오게.

---

## 1. 목표

- 설치 없이 데스크톱·모바일 브라우저에서 바로 플레이
- 30초 한 판, 짧고 반복하고 싶은 게임 흐름
- 외부 서버 없이 정적 호스팅(GitHub Pages 등)으로 배포

### 재미의 세 기둥

| 기둥 | 무엇으로 만드나 |
| --- | --- |
| **손맛** | 타격 순간 멈칫(히트 스톱), 화면 흔들림, 두더지 기절 표정, 점수 팝업 |
| **판단** | 쳐야 할 두더지와 피해야 할 두더지가 섞여 나옴. 빨리 치되 아무거나 치면 손해 |
| **욕심** | 콤보 → 피버, 판마다 미션, 별 3개 평가, 도감 수집, 오늘의 챌린지 |

## 2. 핵심 게임 규칙

| 항목 | 내용 |
| --- | --- |
| 판 구성 | 3×3 구멍 9개 (피버·후반에 4×4로 확장 가능) |
| 제한 시간 | 30초 |
| 두더지 등장 | 무작위 구멍에서 일정 시간 노출 후 사라짐. 안 맞고 들어가면 "메롱" 하고 놀림 |
| 헛치기 | 빈 구멍을 치면 망치가 0.3초 경직(콤보는 유지) — 막 두드리기를 막되 짜증은 덜하게 |
| 놓치기 | 쳐야 할 두더지가 그냥 들어가면 콤보 초기화 |
| 종료 | 시간 종료 시 결과 화면(점수, 등급, 명중률, 최고 콤보, 미션 결과) |

### 두더지 도감

| 두더지 | 등장 | 특징 | 점수 |
| --- | --- | --- | --- |
| 🐹 보통 두더지 | 항상 (전체의 약 55%) | 기본 | +10 |
| ⭐ 황금 두더지 | 판당 6–7마리 (첫 등장 확정, 10마리 연속 안 나오면 다음은 반드시 황금) | 노출 시간 65% | +30 |
| ⛑️ 헬멧 두더지 | 10초~, 판당 약 4마리 | 두 번 쳐야 함. 첫 타에 헬멧이 날아감 | +25 |
| 💨 날쌘 두더지 | 10초~, 판당 약 4마리 | 한 번 숨었다 옆 구멍으로 튀어나옴 | +20 |
| 💣 폭탄 두더지 | 5초~, 판당 약 6마리 | 폭탄을 들고 있음. 치면 화면이 흔들리고 콤보 초기화 | −20 |
| ⏰ 시계 두더지 | 행운 (두 판에 한 번꼴, 판당 최대 2회) | 남은 시간 +3초 | +5 |
| 🧊 얼음 두더지 | 행운 (세 판에 두 번꼴, 러시에 더 자주) | 2초간 모든 두더지 느려짐 | +10 |
| 👑 왕 두더지 | 마지막 5초 1회 | 5번 연타해야 쓰러짐. 연타할수록 표정 변화 | +100 |

처음 잡은 두더지는 잡는 즉시 "NEW!" 표시와 함께 도감에 등록되고(판 도중에 나가도 유지), 시작 화면의 도감에서 누르면 점수·타격 수·등장 시점·설명과 지금까지 잡은 수를 볼 수 있습니다. 아직 못 만난 칸은 ❔로 잠겨 있습니다.

### 콤보와 피버

- 콤보 배율: 0–4콤보 x1 → 5–9콤보 x2 → 10콤보 이상 x3
- **피버 타임**: 15콤보 달성 시 5초간 발동
  - 점수 x2 추가, 폭탄 등장 안 함, 보통 두더지가 한꺼번에 쏟아짐
  - 배경색 전환, 효과음 음높이 상승, 망치가 불꽃 망치로 변신
- 콤보 단계가 오를 때마다 "Nice! → Great! → Awesome!" 텍스트 연출

### 한 판의 흐름 (30초)

| 구간 | 이름 | 등장 간격 | 노출 시간 | 동시 등장 최대 (폭탄) | 새로 나오는 것 |
| --- | --- | --- | --- | --- | --- |
| 0–5초 | 워밍업 | 850ms | 1,100ms | 1 (0) | 보통, 황금(두 번째에 확정) |
| 5–10초 | 폭탄 주의 | 750ms | 1,000ms | 2 (1) | 폭탄(확정) |
| 10–20초 | 혼전 | 620ms | 850ms | 2 (1) | 헬멧·날쌘(차례로 확정), 시계, 얼음 |
| 20–25초 | 러시 | 480ms | 650ms | 3 (2) | 폭탄·얼음 비율 증가 |
| 25–30초 | **라스트 스퍼트** | 430ms | 600ms | 3 (2) | 왕 두더지, 황금 비율 증가, 점수 x1.5, 화면 테두리 붉게, 째깍 소리 |

| 구간 | 보통 | 황금 | 폭탄 | 헬멧 | 날쌘 | 시계 | 얼음 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 워밍업 | 92 | 8 | – | – | – | – | – |
| 폭탄 주의 | 76 | 6 | 18 | – | – | – | – |
| 혼전 | 53 | 6 | 14 | 11 | 11 | 2.5 | 2.5 |
| 러시 | 45 | 6 | 18 | 10 | 11 | 4 | 6 |
| 라스트 스퍼트 | 54 | 12 | 16 | 8 | 10 | – | – |
| 피버 | 75 | 25 | – | – | – | – | – |

재미를 위한 규칙
- **확정 등장**: 새 두더지는 자기 구간 초반에 반드시 한 번 나와 소개된다(확정 등장끼리는 3마리 이상 간격)
- **연속 금지**: 같은 특수 두더지(폭탄 포함)는 두 번 연달아 나오지 않는다
- **폭탄 상한**: 동시에 나와 있는 폭탄 수를 구간별로 제한해 판이 폭탄밭이 되지 않게 한다
- **황금 보정**: 황금이 10마리 연속 안 나오면 다음은 반드시 황금

수치는 플레이 테스트 후 조정합니다.

### 판마다 미션

시작할 때 미션 1개가 무작위로 제시되고, 달성하면 보너스 +50점과 별 조건에 반영됩니다.

- 황금 두더지 3마리 잡기
- 폭탄 한 번도 안 치기
- 20콤보 달성
- 왕 두더지 쓰러뜨리기
- 명중률 90% 이상

### 평가와 "한 판만 더"

- **등급**: 점수 구간별 S / A / B / C, 별 1–3개(점수 600 이상 · 미션 달성 · 폭탄 0회이면서 놓친 두더지 5마리 이하)
- **다음 목표 제시**: "신기록까지 70점!", "헬멧 두더지를 아직 못 잡았어요" 같은 한 줄
- **결과 공유**: 이모지 요약을 클립보드에 복사

```
Project Hammer 🔨 10/19
⭐⭐☆  A등급 · 1,240점
🐹×38 ⭐×4 ⛑️×3 👑 💣×1
최고 콤보 22 🔥
```

### 오늘의 챌린지

날짜를 시드로 쓰는 난수로 등장 패턴을 고정해, 같은 날에는 모든 플레이어가 같은 판을 칩니다. 친구와 같은 판 점수를 비교할 수 있고, 서버 없이 구현됩니다(6장 "시간·난수 주입" 활용).

### 랭킹 (온라인, Firebase Firestore)

- **저장소**: Firebase `joypack` 프로젝트의 Firestore를 다른 게임과 같이 쓰며, 두더지잡기는 `games/hammer/rankings/` 아래에만 둔다. 순위표 하나가 문서 하나다(`classic`, `daily-YYYY-MM-DD`). 등록은 트랜잭션으로 해서 동시에 올려도 규칙이 깨지지 않는다(`src/online.ts`)
- **오프라인**: 마지막으로 불러온 순위를 기기에 남겨 두고 보여 준다. 등록하지 못한 기록은 등록 대기로 남는다
- **보안 규칙**: `games/hammer/rankings/{board}`만 읽기·쓰기 허용, 문서 이름은 `classic`·`daily-날짜`만, 필드는 `entries`(10개 이하)만, 삭제 금지

- **두 개의 순위표**: 클래식 / 오늘의 챌린지. 오늘의 챌린지 순위표는 매일 자정(기기 시각)에 새로 시작한다
- **1~10위**: 10위 안에 드는 점수가 나오면 끼워 넣고 11위로 밀린 최하위를 지운다. 같은 점수면 먼저 올린 기록이 앞선다(10위와 같은 점수는 들어가지 못함). 0점은 올리지 않는다
- **이름**: 영문 대문자 A–Z 최대 5자. 소문자는 대문자로 바꾸고 다른 글자는 입력 단계에서 거른다. 지난번 이름을 미리 채워 둔다
- **등록 흐름**: 결과 화면에서 페이지를 옮기지 않고 점수 바로 아래 카드에서 이름을 받는다("랭킹 4위 진입!"). 이름이 채워져 있으면 등록 버튼에 초점이 있어 Enter 한 번이면 끝난다. 휴대폰 자판이 저절로 뜨지 않도록 입력 칸에는 자동 초점을 두지 않는다
- **놓쳐도 괜찮게**: 10위 안에 들면 먼저 "등록 대기"로 저장한다. 등록하지 않고 다시 하기·홈으로 가도 메인의 랭킹 버튼에 점이 찍히고, 랭킹 창 맨 위에서 나중에 올릴 수 있다(그사이 10위 밖으로 밀렸거나 오늘의 챌린지 날짜가 지나면 사라짐)
- **메인의 랭킹 버튼**: 최고 기록 아래. 클래식·오늘의 챌린지 탭, 1~3위 메달, 방금 올린 줄 강조

## 3. 화면 구성

1. **시작 화면** — 타이틀(두더지가 구멍에서 들락날락), 클래식 / 오늘의 챌린지 선택, 최고 기록, 랭킹 버튼(등록 대기 기록이 있으면 점 표시), 도감(눌러서 설명 보기), 사운드 켜기/끄기
   - 좌상단: 언어 전환(한국어 / English)
   - 우상단 ⚙️ 설정: 컬러 모드(기기 설정 / 라이트 / 다크), 스킨(자동 / 정원 / 사막 / 밀림 / 설산 — 자동은 날짜마다 바뀜), 언어, 게임 리셋(최고 기록·랭킹·도감만 지우고 설정은 유지, 한 번 더 확인)
2. **게임 화면** — 상단 HUD(점수 · 남은 시간 · 콤보 게이지 · 미션), 구멍 그리드, 망치 커서
3. **카운트다운** — 시작 전 3·2·1·GO!
4. **일시정지** — 계속하기 / 다시 시작 (탭 전환 시 자동 일시정지)
5. **결과 화면** — 점수가 차르르 올라가는 연출, 등급·별, 10위 안이면 랭킹 이름 등록 카드, 미션 결과, 신기록 폭죽, 다음 목표, 공유, 다시 하기(스페이스바·탭 한 번)

## 6. 설계 원칙

- **로직과 화면 분리**: `game/`은 DOM을 모르고 상태만 다룬다. `ui/`는 상태를 받아 그린다. 로직은 Vitest로 단독 테스트 가능하다.
- **시간·난수 주입**: 엔진은 `now()`와 난수 함수를 주입받는다. 테스트에서 시간과 등장 위치를 고정할 수 있고, 같은 원리로 오늘의 챌린지(시드 난수)를 만든다.
- **두더지는 데이터로**: 종류별 차이를 `moles.ts`의 정의 표로 두어, 새 두더지를 코드 분기 없이 추가한다.
- **이벤트로 연출 연결**: 엔진은 `hit`, `miss`, `whiff`, `comboUp`, `feverStart` 같은 이벤트만 내보내고, 연출·사운드·진동은 그 이벤트를 구독한다.
- **상태 머신**: `ready → countdown → playing ⇄ paused → over` 다섯 상태만 두고 전이를 한 곳에서 관리한다.
- **입력**: `pointerdown` 하나로 마우스·터치를 함께 처리해 모바일 클릭 지연을 피한다.
- **움직이는 배경**: 스킨마다 하늘·해(밤에는 초승달)·먼 산·중간 언덕·가까운 땅을 SVG로 그려 깔고, 세 겹이 서로 다른 속도로 흐르며 포인터나 기기 기울기에 따라 겹마다 다르게 밀려 깊이감을 낸다. 구름과 스킨별 입자(꽃잎·모래바람·반딧불·눈)가 떠다니고, 강조색과 면 색도 스킨 빛깔을 따른다. 움직임 줄이기 설정에서는 멈춘다.
- **화면 맞춤**: 세로 360×640 · 가로 640×360을 설계 기준으로, 모든 크기를 `em` 하나로 비율 조정해 어떤 창 크기에서도 스크롤 없이 한 화면에 들어간다. 휴대폰 320×568(가로 568×320)부터 태블릿 768×1024(가로 1024×768)까지 커지고, 그보다 큰 화면에서는 휴대폰·태블릿(터치가 주 입력)은 이 크기로 가운데 정렬하고, PC(마우스·트랙패드가 주 입력)는 창 크기에 맞춰 계속 커진다. 가로 화면에서는 HUD와 판을 좌우로 나눈다.
- **프레임 루프**: `requestAnimationFrame`으로 타이머와 등장 스케줄을 갱신하고, 탭이 숨겨지면(`visibilitychange`) 일시정지한다.

## 8. 실행 방법

패키지 매니저는 pnpm을 사용합니다.

```bash
pnpm install
pnpm run dev      # 개발 서버 (http://localhost:5173)
pnpm run test     # 단위 테스트
pnpm run build    # 타입 검사 후 dist/ 에 정적 빌드
pnpm run preview  # 빌드 결과 미리보기
```
