# 전역 기본 지침 (모든 프로젝트 · 신규 프로젝트 공통)

## [답변 언어] — 항상 한국어 (최우선, 압축 후에도 동일)

- 모든 답변·설명·중간 안내·작업 보고·질문은 **반드시 한국어**로 쓴다. 코드·식별자·명령어·파일 경로만 원문 그대로 둔다.
- `/compact` 등으로 대화가 압축된 뒤에도 똑같이 지킨다. 압축 요약문이나 이전 메시지·도구 결과가 영어여도 영어로 답하지 않는다.
- 답변을 보내기 전에 본문이 한국어인지 한 번 더 확인한다.

## [진행 시간·토큰] — 항상, 답변 본문을 마친 뒤 별도 메시지로

- 답변 본문에는 시간·토큰을 쓰지 않는다. 본문을 끝낸 뒤 **별도 메시지**에 이 한 줄만 쓴다:
  `00시 00분 00초 · 0,000 토큰`
- 그 별도 메시지는 측정 대상이 아니다. 거기에 다시 시간·토큰을 붙이지 않고, 어떤 제외 단서도 달지 않는다.
- **기준값**: 그 턴의 첫 도구 호출 때 시각과 누적 usage를 잰다. 측정을 지시한 그 호출 1건은 이미 기록돼 있으므로 빼고 합산한다.
- **최종값**: 답변 본문을 쓰는 메시지 안에서 측정을 함께 수행하고, 이때는 마지막 1건을 빼지 않는다. 본문을 생성한 API 호출은 그 시점에 이미 jsonl에 기록돼 있어 합계에 들어간다.
- 도구를 쓰지 않는 턴은 본문 메시지의 측정 한 번으로 기준값(마지막 1건 제외)과 최종값(제외 없음)을 같이 얻는다.
- 시간·토큰 모두 **기준값과 최종값의 차이**를 쓴다. 토큰은 `input + output + cache_creation + cache_read` 합계이며 세 자리마다 쉼표를 찍는다.
- 토큰은 `~/.claude/projects/*/<세션ID>.jsonl`에서 실측한다. assistant 항목의 `message.usage`를 `message.id`로 중복 제거해 합산하고, 턴 시작은 `message.content`가 문자열인 `type=="user"` 항목이다(list면 tool_result). 출력에는 thinking 토큰이 포함된다.
- 시각·usage 중 재지 못한 항목은 **"측정 불가"**로 쓴다. 추정을 실측처럼 쓰지 않는다.
