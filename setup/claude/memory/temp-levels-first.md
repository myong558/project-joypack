판(레벨) 생성에 시간이 많이 드는 게임은 최종 제작 전까지 테스트하기 부담 없는 만큼만(빠른 설정의 임시 판, 날마다 판은 2주 치 정도) 만들어 진행한다. 게임이 거의 완성되면 "나머지 판 생성"을 사용자에게 먼저 제안하고 승인받아 돌린다.

**Why:** 2026-10-25 온실 정원 규칙 변경 때 화분 3개 판 고르기가 판마다 몇 분씩 걸려 작업이 오래 멈춤. 사용자가 이렇게 하라고 지시하고 기준서 0장·7.4 에 등록하게 함.

**How to apply:** 새 게임·규칙 변경에서 판 생성이 몇 분을 넘을 것 같으면 빠른 설정으로 임시 판을 만들고, 판 데이터·README 에 "임시" 표시. 정식 공개 전(기준서 7.4 0단계)에는 반드시 고품질 생성 완료.
