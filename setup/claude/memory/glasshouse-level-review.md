온실 정원(games/glasshouse)은 출시 전 판 점검 단계다(2026-11-04 기준 v0.14.2).

- 사용자가 개발자 모드의 "풀이 보기"(판 아래 ◀ 밀기 n / 전체 ▶ ▶▶ 줄, v0.14.0~0.14.1)로 24판을 직접 풀어 보고, **판 구조 수정·순서 변경을 따로 전달하기로 했다.** 그 요청이 오면 판(src/game/levels.ts)을 고친다.
- 판을 바꾸면 반드시 `pnpm --filter glasshouse solutions` 로 풀이(src/game/solutions.ts)를 다시 만든다. 안 하면 tests/levels.test.ts 가 실패한다. par(기준 이동 수)·화분 수 곡선 테스트도 함께 맞춘다.
- 판별 난이도 수치(화분·이동·밀기·돌려놓기·점수)는 src/game/roomgen.ts 의 `rate()` 로 잴 수 있다. 2026-11-04 기준 점수가 앞 판보다 낮은 판은 4판(131 < 3판 132)·6판(140 < 5판 157)뿐이다.
- **2026-11-07 판 만들기 과정을 `tools/levelmake.ts` 파이프라인으로 고도화**(역방향 탐색 + 빠른 판 재기, 이전 방식보다 후보 35배↑, 화분 4~5개도 5분에 후보가 나옴). 판은 안 바꿈. 새 후보 점수가 지금 끝 판(554)을 넘어(최고 785) `tools/levelplan.ts` 점수 범위를 새로 정해야 판을 다시 고를 수 있음 → 판을 다시 고르자고 하면 먼저 새 곡선(7 → 24 점수)을 제안해 정한 뒤 `levelmake gather` → `pick` → `pick --write`.
- **2026-11-07 체감 난이도 요소 추가**(`levelmake report`, `tools/difficulty.ts`): 결정점마다 숨은 함정·유혹 함정·외길·화분 바꾸기·돌려 놓기 + 사람 흉내 봇 → 체감 점수(가중치 `levelplan.ts` HUMAN_WEIGHTS, **가설값**). 지금 판은 체감 점수로 9판이 앞 판보다 낮음(8·10·11·13·14·16·19·20·23), 11·16판은 생각할 것이 적음. 사용자가 판을 풀어 본 체감 순서를 알려 주면 가중치를 맞춘다.
- **2026-11-08 v0.23.0 판 다시 고름**: 사용자 체감(11<10, 16<15, 22≈24)으로 숨은 함정 가중치 0.5, 곡선 "끝으로 갈수록 가파름"·24판 250·벗어난 판만·체감 기준(객관식 선택). 바뀐 판 8·10~21·23·24 → **사용자가 풀이 보기로 새 판 확인 필요**. 모의 플레이 보통 19~24 평균 372 → 679초(약 11분)로 끝 판이 꽤 길어짐 — 너무 어렵다고 하면 `levelplan.ts` 목표를 낮춰 `levelmake pick --write`.
- 판 고르기 화면에 난이도 숫자를 붙이는 "제안 2"는 사용자가 채택하지 않았다(풀이 보기만 적용).

**Why:** 사용자가 직접 플레이 체감으로 판 난이도·순서를 다듬으려 한다.
**How to apply:** 사용자가 판 번호와 함께 수정·순서 변경을 말하면 이 흐름대로 진행한다. 관련 조작 결정은 [[glasshouse-push-controls]].
