온실 정원(games/glasshouse) 조작 개편. 2026-11-03에 사용자와 논의했고 v0.13.0 에서 구현했다(20px 넘는 순간 한 칸, 손 뗄 때까지 더 안 감, 빠른 연속 드래그는 2개까지 줄 세워 90ms 간격).

- 드래그(스와이프)는 한 번에 한 칸만 간다. 화분 밀기도 드래그를 한 번씩 반복한다. 손을 떼지 않아도 더 가지 않는다(예전에는 칸의 55% 거리마다 반복해서 실수가 났음).
- 빈칸을 누르면 최단 경로로 걸어가는 기능, 옆 칸 누르기, 키보드 조작은 그대로 둔다.
- **희미한 화분 UI(화분이 갈 수 있는 칸에 희미한 그림을 깔고 눌러 밀기)는 한때 합의했다가 사용자가 폐기했다.** 다시 제안하지 않는다.
- **무르기(되돌리기)는 넣지 않는다.** 사용자가 "치팅 수준"이라고 거절했다.
- 십자 버튼(2G 폰식)은 판이 작아지고 4칸도 4번 눌러야 해서 채택하지 않았다.

**Why:** 계속 밀면 여러 칸을 가서 생기던 실수를 없애려는 것이다. 사용자는 화면 요소를 늘리지 않고 단순한 규칙 하나를 원한다.
**How to apply:** 온실 정원 조작을 구현하거나 고칠 때 이 결정을 따른다.
